# Wu04／Wu08 研究源码收拢

本目录保存原双筛路线的已交付证明、明确的未闭接口、必要的历史版本，以及可独立运行的源码重建入口。**它不是 Wu08 最终 1.8938 定理已经形式化完成的声明。** 既有 Goldbach 发布入口及其默认构建目标未被修改。

## 分支与保存范围

本项目统一维护在 `1.8938` 分支，Goldbach 主线维护在 `main`；后续本项目修改不直接合入主线。此前已进入 `main` 的研究快照未作回滚。

旧工作按源码内容、来源清单和历史变体收拢，不要求把相互冲突的旧版本同时放入可编译入口。`src/` 保存整合版本，`history/` 保存旧工作树的独有源码及未选用变体。75个旧工作树已完整归档，经逐文件散列校验与独立解包恢复验证后撤除；本地本项目只保留 `1.8938` 整合工作树。原 Git 历史、未提交字节及运行证据保存在本地私有冷归档，不再作为工作树。

独立全量重建已按用户要求停止，尚未通过完整验收；停止构建不影响源码保存和上传。

## 布局

- `src/`：从实际编译对象导入图恢复的源码。顶层 `Wu2008Research` 联合导入本轮原文路线的交付入口。
- `source-manifest.json`：模块、源码 SHA-256、原对象指纹及导入关系。`matching_source_variants` 大于一表示存在多个同导入表源码版本；这不是源与对象等价已经证实的标志，必须经过重建及接口检查。
- `roots.json`：原文路线默认入口，以及其他已编译研究入口。后者含较早替代路线，不能用于宣称原文路线已经闭合。
- `history/`、`history-manifest.json`：75个旧工作树已纳入保存登记，其中74个含工作区 Lean 源码，另一个仅有 Git 元数据。6365条原相对路径记录对应2201份不同源码；包括失败尝试和诊断程序。**历史目录不参与默认构建，不保证每个历史版本都能编译。** 初次搜集的3个未选中依赖候选另保存在 `history/initial-source-candidates/`。
- `mathematical-status.json`：本批12项交付的限定验收状态；全局定理状态仍为未完成。
- `build.py`：仅使用本目录源码、固定工具链及固定 Lake 依赖重建。不会加载旧服务器的研究对象路径。

## 复现

工具链及依赖版本固定于 `lean-toolchain`、`lakefile.toml`、`lake-manifest.json`。在本目录执行：

```sh
lake update
lake exe cache get
python3 verify_sources.py
python3 build.py
```

`lake update` 后应确认依赖 revision 仍与提交的清单一致；不要以更新工具链来规避错误。数学库缓存可以复用，研究证明对象必须由本目录源码产生。详细构建命令和成功／失败回执保存在未纳入 Git 的 `build/` 中。

```sh
# 检查额外研究入口；不编译 history 中的失败或旧变体
python3 build.py --all
```

构建可中断并继续；仅在源码、依赖对象及输出指纹均一致时复用成功回执。超时、失败和完整成功分别记录，不能把一次分批退出0解释为全量通过。

## 数学范围

- 已验收四个固定 Ψ₁ 高素数窗的真实计数、原积分系数及既有数值下界；这不等于一般 Proposition 4.4 或完整七窗。
- 完整 Ξ₁／Ξ₂ 积分核身份、换序、可积性及实际 Ξ₁ 五行反馈已交付；实际 Ξ₂ 最终功能不等式仍缺上游输入。
- 原矩阵的81个符号系数身份及单调离散已交付；原实际九行系统及其数值求解未完成。
- Ψ₂ 三个高窗只付清前八个有号 Γ 项，结论仍保留十三项实际计数。
- 十三项独立上确界费用已有严格预算运输；Buchstab 函数低于1的两种明确延拓分别保留，原文字面约定未擅自裁定。
- 原 Γ₅ 全域实际收益、原 raw/prefix 母式差额、完整十一项有号余量和最终数值总账仍有未闭部分。

公开已验收定理的标准逻辑公理检查仅允许 `propext`、`Classical.choice`、`Quot.sound`；这与定理类型中明确写出的数学条件是不同层次。历史变体、导入目录或源文件数量都不代表全局数学完成。
