\chapter{The public proof boundary}

The project formalizes Chen's $1+2$ and Li--Liu's $1+1.9$ theorems, while
building reusable analytic number theory toward stronger Goldbach results.
The public imports are separate: \texttt{Goldbach} retains the Chen interface,
\texttt{Goldbach.OnePlusOneNine} exposes Li--Liu, and \texttt{Goldbach.All}
combines them.

Li--Liu's theorem gives, for every sufficiently large even natural number $N$,
primes $p,q$ and a natural number $r$ with $r=1$ or $r$ prime, such that
\[
N=p+rq, \qquad r^{10}\le q^9.
\]
The real-power endpoint gives the equivalent condition $r\le q^{9/10}$.
Its count $D_{1,19/10}(N)$ counts distinct eligible primes $p$, once for each
prime, and satisfies
\[
\frac{1}{2500}\,\mathfrak S_{\mathrm{Liu}}(N)
\frac{N}{(\log N)^2} < D_{1,19/10}(N)
\]
for all sufficiently large even $N$. Here $1/2500=0.0004$ exactly and
\[
\mathfrak S_{\mathrm{Liu}}(N)=
\prod_{\substack{\ell>2\ \mathrm{prime}\\\ell\mid N}}
\frac{\ell-1}{\ell-2}
\prod_{\ell>2\ \mathrm{prime}}\left(1-\frac{1}{(\ell-1)^2}\right).
\]
For each fixed real $\kappa<515093/800000000$, the development also proves an
eventual non-strict lower bound with coefficient $\kappa$ in this normalization.
The threshold is chosen after $\kappa$.

The exact public declarations and their implementation imports are in
\texttt{Goldbach/OnePlusOneNine.lean}; the repository's theorem guide records
the definitions and quantifiers.

\chapter{Sources and verification}

The development builds on UyNewNas/chen-theorem-lean and the attributed analytic
number theory sources, with upstream copyright notices retained under Apache-2.0.
The provenance guide records these sources and the Li--Liu mathematical inputs.

Existing builds can retain the \texttt{.lake/} directory when updating: the
package configuration, toolchain and dependency pins are unchanged. Lake reuses
unchanged dependencies and rebuilds new or affected modules as needed; the README
gives focused build and upgrade commands.

The source repository includes the literal specifications, the full proofs,
release notes, attribution, and instructions for rebuilding and checking the
public theorems. Verification combines a source build, literal-statement and
axiom checks, and independent replay; the graph provides source navigation.
