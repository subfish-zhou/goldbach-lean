    The global Buchstab delay function #

    Continuous integral approximants stabilize on successively larger half-lines. Their locally stable value defines a function on all of ℝ; on [1, ∞) it satisfies the initial condition and the Buchstab delay differential equation. The extension below 1 is only used to keep the approximants globally continuous.
