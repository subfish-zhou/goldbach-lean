    The exact Buchstab logarithmic integral #

    The primitive -(L / log t) * buchstab (L / log t) / L evaluates the logarithmic kernel. The fundamental theorem is used only on the interior: the upper endpoint, where the Buchstab argument is 2, needs continuity but not differentiability. In particular the square endpoint is included.
