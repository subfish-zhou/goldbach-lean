    High-order support of the actual small-weight density boundaries #

    For the source parameters L = D^ε, u = D^(ε²), a failed cubic test L ≤ (∏ s) q³ involving small primes forces 1 < ε (|s| + 3). The finite boundary kernels are therefore sums over these high layers only. This localizes the explicit errors; it does not estimate their total size.
