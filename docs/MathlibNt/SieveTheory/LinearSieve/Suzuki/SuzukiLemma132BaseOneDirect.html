    Direct N = 1 base for Suzuki Lemma 13.2 #

    At κ = 1, β = 2, the first finite source layer is explicit. On its legal odd-parity domain x > 1, its weighted value is 3 - x for x ≤ 3 and is zero for x ≥ 3. The Section-13 initial condition says that the weighted positive hat layer is exactly one on 0 < x ≤ 3. Thus the fixed constant 2 proves the whole N = 1 layer, including the zero-support tail.
