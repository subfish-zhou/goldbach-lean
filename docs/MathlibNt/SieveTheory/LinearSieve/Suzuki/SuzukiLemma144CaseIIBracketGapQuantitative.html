    Quantitative Case-II rounded-bracket gap #

    The existing contraction proof spends only 5/32 of the source tangent gap: the integral-transport excess costs 1/32 and the four endpoint terms cost 4/32. Thus the rounded bracket retains 27/32 of (1-Δ)/sourceSigma D d. In particular the true proved scale is 1/σ, stronger than the requested 1/(loglog D * σ) scale.
