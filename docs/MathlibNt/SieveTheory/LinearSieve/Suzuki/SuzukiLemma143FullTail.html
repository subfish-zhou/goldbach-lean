    Suzuki Lemmas 14.1--14.3: explicit uniform exponential tail #

    This file closes the dimension-one local-product hypothesis into the pointwise Lemma 14.1 source estimate and then combines the natural-ceiling support theorem with Lemma 14.2. The resulting bound is uniform in N.
