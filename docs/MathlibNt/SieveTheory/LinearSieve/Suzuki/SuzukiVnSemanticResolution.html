    Exact integral outer carrier in Suzuki Lemma 7.1 for beta = 2.

    n is the complete source index. D <= p^(n+2) is y_n <= p; for odd n, p^3 < D is the extra upper cutoff in z_n = min(z,D^(1/3)).
