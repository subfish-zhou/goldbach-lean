      The exact finite normalized base object V₁(D,z)/V(z) from Lemma 7.1:

      ∑_{y₁ ≤ p < z} ν(p) V(p)/V(z).

      Only supported primes occur, as required by the finite BoundingSieve model. The D argument in the production prime-sum is the power-coordinate parameter; for the constant test function used here it does not affect the value.
