    structure MathlibNt.SieveTheory.Claim145SourceParameterPacket (Δ₀ Δ d Θ : ℝ) :
    Prop

    The parameter inequalities chosen on Suzuki p.81, equations (14.3) and (14.4). Keeping them together prevents later consumers from silently assuming extra size conditions on Θ.

    • delta0_le_one : Δ₀ ≤ 1
    • delta_nonneg : 0 ≤ Δ
    • d_pos : 0 < d
    • theta_pos : 0 < Θ
    • equation14_3 : 2 / d < 1 / Θ
    • equation14_4 : 2 / Θ + 3 / d < Δ₀ - Δ
