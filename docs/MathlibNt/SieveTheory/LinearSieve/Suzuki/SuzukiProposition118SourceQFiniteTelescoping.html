    Finite source-Q weighted derivatives and telescoping #

    This module closes the finite, source-level calculus behind Suzuki Proposition 9.3(iii) and Proposition 9.4(vi), specialized to κ = 1, β = 2.

    The base layer is kept separate. On 2 < s < 3, its weighted derivative is -1; this is the term which combines with the even-layer derivatives to recover the prescribed history Q(s-1) = A_m/(s-1). Above 3, the ordinary layer recurrences telescope, leaving only the last even layer.
