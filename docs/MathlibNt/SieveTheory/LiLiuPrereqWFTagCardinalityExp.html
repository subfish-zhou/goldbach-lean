    The exponential bound for the actual normalized signed family #

    Bernoulli's inequality gives the coarser alphabet size ⌊ε⁻¹¹⌋ + 1, which is already sufficient without the logarithmic grid-count estimate. The elementary inequality log t ≤ t / 2 then absorbs this alphabet and the length bound into exp (8 ε⁻³).
