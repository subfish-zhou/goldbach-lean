    A uniform bound for the actual normalized signed tags #

    The finite set here is the existing signedTags, with one member for each accepted multiplicity profile, including the empty profile. No factorial copies are introduced. The estimates do not require any condition on the supplied prime labelling: numerical acceptance itself bounds every label.
