    Exact density defects for the actual small Rosser weights #

    The finite starting point for Iwaniec (1980), p.316 (22). The boundary is a failed cubic test at the newly inserted least prime, with equality on the failure side. The lower error is subtracted and the upper error is added. No analytic estimate for these explicit errors is assumed or asserted.
