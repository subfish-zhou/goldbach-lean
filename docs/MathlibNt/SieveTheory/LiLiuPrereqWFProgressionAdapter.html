    The reduced-residue discrepancy and its actual coprime-mass correction #

    Fouvry's discrepancy subtracts the modulus-dependent coprime mass, not a fixed X / φ(d). The identity below displays that difference explicitly. For a set of primes its correction is bounded by finite harmonic sums; no equidistribution theorem is asserted or assumed.
