    Exact finite Selberg optimization for Liu's source modulus #

    Liu's lemma lm-selberg states the existence of coefficients with main term [8 + O(ε)] 𝔖(N) / log N; it does not prove the finite minimization in the form needed by this development. This file performs that minimization exactly. After it, the genuinely analytic missing statement is precisely the eventual, uniform weighted Mertens--Selberg lower bound for ∑_{l ∣ Q, l ≤ R} ∏_{p ∣ l} 1 / (p - 2).
