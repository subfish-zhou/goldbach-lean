    Transport to full-modulus sums without masking the WF coefficients #

    The exact transport holds for arbitrary indexed sequences, including zeros and multiplicities. Its quantitative version has separate, explicit sequence hypotheses and uses the canonical arithmetic-progression density 1 / φ(d) on reduced residue classes. A prime-only dimension-one condition is never used to control arbitrary prime-power densities.
