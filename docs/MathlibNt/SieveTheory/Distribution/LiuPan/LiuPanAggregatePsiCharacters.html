    Character reduction for Liu's aggregate psi term #

    This module gives exact finite character identities for the aggregate source-convolution psi discrepancy. It separates the principal character before any absolute value or character Cauchy--Schwarz inequality, and then regroups the nonprincipal part by primitive conductor.
