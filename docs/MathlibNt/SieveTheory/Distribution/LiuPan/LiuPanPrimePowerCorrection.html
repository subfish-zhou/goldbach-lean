    Global bound for Liu's AP prime-power correction #

    This module bounds the progression-restricted correction by the unrestricted nonprime von Mangoldt sum. On nonzero von Mangoldt support, n >= 2, so the normalizing logarithm is bounded below by the exact constant log 2.
