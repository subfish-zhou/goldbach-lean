    Actual prime-count centering in Wu (2004), equation (5.7) #

    Both discrepancies use the same actual AP count. The main term here is the actual number of primes, not li. Their difference is the principal error summed over the modulus-dependent coprime source set, before taking absolute values. The balanced PNT estimate pays this filtered difference uniformly.
