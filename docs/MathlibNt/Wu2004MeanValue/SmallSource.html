    Small-coefficient Wu errors with fully independent real endpoints #

    For a logarithmically small coefficient carrier it suffices to use the same ordinary AP prefix maximum for each coefficient. We deliberately pay the whole cardinality, rather than rescaling BV separately at every coefficient. Extra logarithmic saving pays this loss. Endpoints, coefficients and supports can all be selected independently for each modulus.
