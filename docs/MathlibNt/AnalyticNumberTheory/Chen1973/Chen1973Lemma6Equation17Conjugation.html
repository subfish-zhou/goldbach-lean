    Conjugation symmetry for Chen's equation (17) #

    This file proves the conjugation identities for the actual primitive-character family and the actual finite polynomials occurring in equation (17). It then uses those identities to replace the full vertical-line norm integrals by twice the half-line integrals already used in Chen1973Lemma6Equations16And17.
