    Direct Vaughan Type-I: the AP-normalized physical scale #

    The unsquared mean arising from character orthogonality has weight 1 / φ(q). This module keeps that weight through row Cauchy and only then invokes the existing variable-length primitive maximal large sieve. It also records why putting the square-large-sieve weight q / φ(q) on the unsquared mean inserts an extra factor q before any analytic estimate is used.
