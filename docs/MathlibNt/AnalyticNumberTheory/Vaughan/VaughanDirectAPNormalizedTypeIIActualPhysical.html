    Physical AP-normalized bounds for actual Vaughan Type-II shells #

    This file starts with the genuine collected hyperbolic-prefix maximum. It applies prefix-maximal large sieve row by row, sums the rows after paying the Möbius energy, and only then uses Cauchy in primitive characters and moduli.
