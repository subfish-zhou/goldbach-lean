    Actual high-conductor Type-II ledger on one canonical shell #

    The outer row lies in [2^k,2^(k+1)); the collected inner coefficient is cut off by the physical condition r*t ≤ N. Thus every row has the common short length N / 2^k. The theorem below applies the canonical prefix-maximal primitive large sieve row by row and keeps the conductor range R < d ≤ Q.
