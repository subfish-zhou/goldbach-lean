    Quantitative first large-gcd exclusion for the actual nonzero W sum #

    The original progression sum, its zero mode and its Fourier tail are estimated on the identical arbitrary mask supported on gcd(n₁,n₂) > x^η. This excludes the first gcd coordinate, not the union of all five large-gcd coordinates. The beta parameter T is an upper endpoint, not a dyadic lower endpoint. The condition β n ≠ 0 → n ∤ a is retained; its preprocessing is separate.
