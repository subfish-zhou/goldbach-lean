    Standard BV: exact dyadic square-mean to L¹ conversion #

    This module isolates the finite conversion which is needed before any Bombieri--Vinogradov conclusion may be claimed. The AP prefix error is supplied pointwise through the character expansion, not as a final BV premise. Every factor 1/φ(q), q/φ(q), the number of moduli in a block, and the number of conductor cells is retained.

    The character quantity is a genuine prefix maximum. Nothing in this file replaces it by the endpoint y = N.
