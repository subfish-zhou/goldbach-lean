    Block-L¹ weighted primitive consumers for the production Vaughan rows #

    The analytic hypotheses in this file are block-local first-moment estimates for exactly the production Type-I and Type-II coefficients. The finite consumer converts d / φ(d) to the AP normalization on each block, reindexes a disjoint finite block partition exactly, and then uses only the two scalar geometric ledgers. The small lane is the production coefficient at standardBVBalancedSmallCutoff, hence is retained and paid through its square ledger plus high-conductor Cauchy. The former v = min N 1 path remains only as an explicitly named compatibility wrapper.
