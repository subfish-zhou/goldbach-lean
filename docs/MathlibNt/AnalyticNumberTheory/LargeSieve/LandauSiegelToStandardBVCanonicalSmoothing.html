    Canonical smoothing data for the raw Landau--Siegel Standard-BV endpoint #

    This module constructs a fixed nonnegative smooth bump supported in [1/2, 2], normalizes it for the multiplicative measure dx/x, and removes all smoothing data from the final raw-Landau--Siegel-to-Standard-BV headline.
