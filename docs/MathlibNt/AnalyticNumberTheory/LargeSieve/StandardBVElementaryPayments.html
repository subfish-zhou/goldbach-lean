    Elementary scalar payments for Standard Bombieri--Vinogradov #

    This module closes the lanes which require no distributional input. The only analytic inputs left to a final Standard-BV consumer are the low-conductor Siegel--Walfisz estimate and the high-conductor Type-I/II hybrid estimate.
