    Poisson extraction with the same arithmetic mask #

    The exclusions in Fouvry (1984), (8.2)--(8.5), concern the original progression sum, not its truncated nonzero frequencies. This module keeps the same mask on the original sum, zero mode, retained frequencies and tail. No estimate for an unmasked zero mode is restricted to a new subset.
