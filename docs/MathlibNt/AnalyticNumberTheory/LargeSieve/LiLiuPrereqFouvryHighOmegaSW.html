    Uniform coprime Siegel--Walfisz transport at the growing omega cutoff #

    The enlarged family contains every scale x >= T >= 1. The bounded-scale range is paid explicitly, so no saving-dependent lower cutoff is hidden in the index type. Coefficient order is unchanged; the SW sieve order rises by one to include order zero.
