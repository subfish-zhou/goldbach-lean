    Supported-modulus exclusions at the actual C.2 scale #

    For x = 4MT, T ≤ x^(1/10) and L ≤ x^(5/9) imply L ≤ M eventually. This pays the actual progression endpoints and preserves the same mask in the original sum, exact zero mode, and uniformly truncated tail.
