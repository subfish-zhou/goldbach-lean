    A logarithmic joint gcd mean #

    The angular sum is split into its two triangles. The ordinary gcd mean on the shorter side and the existing reciprocal gcd mean on the longer side replace a dyadic-shell argument.

    source
    theorem MathlibNt.AnalyticNumberTheory.LargeSieve.LiLiuPrereqFouvry.mainJoint_angular_mean {A B S : ℕ} (hA : 0 < A) (hB : 0 < B) (hS : 0 < S) :
    ∑ u ∈ Finset.Ioc 0 S, ∑ v ∈ Finset.Ioc 0 S, ↑(u.gcd A) * ↑(v.gcd B) / ↑(max u v) ^ 2 ≤ 2 * ↑((fouvryTau 2) A) * ↑((fouvryTau 2) B) * (1 + Real.log ↑S)

    The angular weight has only one logarithm, with no coprimality condition on the enlarged summation domain.
