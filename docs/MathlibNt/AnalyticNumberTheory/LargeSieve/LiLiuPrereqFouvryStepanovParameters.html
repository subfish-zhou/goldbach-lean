    Integer parameters for the Stepanov construction #

    Harcos, Weil's bound for Kloosterman sums, printed page 12 (pages/harcos-weil-12.png). The coefficient spaces have integer dimension 2 * J * B; the equation space has the actual dimension ∑ k : Fin ell, (B + k.val * (m - 1) + (J - 1)). The ceiling choices below prove the strict inequality between these dimensions.

          structure MathlibNt.AnalyticNumberTheory.LargeSieve.LiLiuPrereqFouvry.StepanovParameterBounds (q m ell B J : ℕ) :
          Prop

          All numerical requirements for the genuine finite-dimensional construction, including its exact equation count and a strict real degree budget.

          • ell_pos : 0 < ell
          • ell_le_card : ell ≤ q
          • three_mul_ell_le : 3 * ell ≤ q
          • card_le_ell_sq : q ≤ ell ^ 2
          • B_pos : 0 < B
          • J_pos : 0 < J
          • coefficient_bound : 2 * (B - 1) + m < q
          • equation_count_lt : ∑ k : Fin ell, (B + ↑k * (m - 1) + (J - 1)) < 2 * J * B
          • degree_budget : ↑(B + (q - 1) / 2 * m + (J - 1) * q + ell * m) < ↑ell * (↑q / 2 + 2 * ↑m * ↑ell)
