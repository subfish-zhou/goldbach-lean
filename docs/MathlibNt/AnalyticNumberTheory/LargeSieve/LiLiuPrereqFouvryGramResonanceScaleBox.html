    The local finite box of occupied resonance bases #

    The box keeps all five independent coordinates (r,n₁,h,n₂',s'). Its frequency interval has the actual fixed sign. Its second beta width is F/d, obtained from the original upper beta support, not from the first beta coordinate. No positivity is assumed for keys with empty occupied carriers.
