      Upper bound for π: the PNT supplies a constant such that π(x) ≤ C·x/log x uniformly for x ≥ 2. This gives the analytic bound ≤ C·N/(a·log(N/a)) for switchingCount ≤ π(N/a) in the three-factor main-term estimate.
