Coverage, external boundary, and cycles

All declarations in the local compiled constant census are included, including generated auxiliaries. A name can occur in several actual module censuses (for example, a regenerated equation lemma); all providers are retained, and reference signatures must agree before graph nodes are merged. Exported axiom-shaped signatures are completed with body-bearing private object parts. External or unresolved constants outside that census are retained by exact name, but are not assigned a package from their spelling or expanded. Local extraConstNames have their own boundary category when no body is available.

This is a static Expr.const graph, not arbitrary reflection, runtime calls, tactic execution, projection metadata, or dynamic lookup. Edges are unique references, not occurrence counts or proof execution order. The inspector preserves each exported reference array’s order. Recursive clusters and self-edges are kept; this graph need not be a DAG. Verified API anchors are used only when supplied by a real API bundle; other declarations link to their owning module at the recorded source commit.
